# Smart Bridge Health Monitoring Website

Responsive front-end prototype for **Smart Bridge Health Monitoring Using IoT Sensors**.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. No npm install or server is required.

## Demo features
- Simulated vibration, strain, temperature and tilt readings.
- Auto-updating vibration trend chart.
- Normal / Warning / Critical status based on illustrative vibration thresholds.
- Event log, sensor inventory and IoT pipeline view.
- Responsive layout for desktop and mobile.

## Important limitation
This is a browser-only educational prototype with simulated values. It is not connected to physical sensors, an ESP32, Wi-Fi/LoRa, or a cloud database. Values and thresholds are illustrative and must not be used for real bridge safety decisions.
